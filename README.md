## Project Overview
This project applies text mining and machine learning techniques to analyze Amazon instant ramen reviews. Our goal was to explore how textual features relate to consumer ratings and to build a predictive model capable of estimating review scores based solely on written text.

---

## Objectives
- Apply text preprocessing and cleaning techniques  
- Perform exploratory analysis on textual data  
- Convert text into numerical representations  
- Implement supervised machine learning models  
- Evaluate and compare model performance  
- Interpret model results and discuss limitations  

---

## Contents
The compendium contains the code, Google Colab notebooks, visualizations, and datasets used to analyze Amazon reviews about instant ramen. It is organized as follows:

### `figures and visualization/`
Contains all exported charts and graphics used in the project, including sentiment plots, topic modeling outputs, and the SVM confusion matrix.

### `data/`
Contains all datasets used in the project:
- The cleaned ramen review dataset  
- The synthetic (fake) reviews used to test the SVM model  
- The CSV containing SVM predictions on the synthetic reviews  

### Google Colab Notebooks
Each notebook is uploaded separately and corresponds to a major project component:
- Dataset filtering and preprocessing (Kaggle → ramen subset)  
- Sentiment Analysis  
- Topic Modeling  
- Machine Learning Model (SVM and comparisons)
